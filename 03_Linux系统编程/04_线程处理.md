# 线程处理

## Linux线程简介

- 线程是进程内的执行单元，共享进程的地址空间、代码段、数据段、文件描述符、信号处理等资源，每个线程有自己的栈空间。
- 同一进程的线程之间共享地址空间，数据交换比进程间通信方便，但共享数据会带来线程同步问题。
- 线程的创建、销毁和切换开销比进程小，因此多线程比多进程更适合高并发场景。
- 线程相关函数来自pthread共享库，使用前需要包含头文件`#include <pthread.h>`。

## 线程创建

### pthread_create

原型：

`int pthread_create(pthread_t *thread, const pthread_attr_t *attr, void *(*start_routine)(void *), void *arg);`

- 参数1为线程号的存储位置，创建成功时把新线程的ID写入该位置。
- 参数2为线程属性，可以设置优先级、栈大小等，不需要定制时传入`NULL`使用默认属性。
- 参数3为线程入口函数，是一个函数指针，其参数和返回值必须为`void *(*)(void *)`。
- 参数4为传给入口函数的参数，可以传入任意指针，没有参数时传`NULL`。
- 成功返回0，失败返回非0错误码。
- `pthread_t`定义在`pthreadtypes.h`中，是`unsigned long int`的别名。
- 入口函数的参数和返回值都是`void *`，需要传多个值时可以把数据包装成结构体，把结构体指针作为参数，返回时也可以返回结构体指针。
- 线程创建后需要由`pthread_join`或`pthread_detach`管理，否则线程结束后资源不会自动回收。

## 线程终止

线程终止有以下三种方式：

- 线程函数执行`return`；
- 线程函数内部调用`pthread_exit`；
- 其他线程调用`pthread_cancel`。

### pthread_exit

`void pthread_exit(void *retval);`

- 结束调用它的线程，效果相当于在线程函数里执行`return`。
- `retval`是该线程结束时向其他线程传递的信息（返回值），所指向的内存不能放在线程函数的栈内，因为线程结束后栈会被释放。其他线程需要通过`pthread_join`获取这个`retval`。

### pthread_join

`int pthread_join(pthread_t thread, void **retval);`

- 功能：阻塞等待指定线程结束，获取它的返回值，并在结束后回收线程资源。
- 参数1为线程ID；参数2用于接收对应线程结束时返回的值，不关心返回值时传`NULL`。
- 成功返回0，失败返回错误码。

### pthread_detach

`int pthread_detach(pthread_t thread);`

- 默认创建的线程是可join状态，即可以通过`pthread_join`等待并回收。如果既不join也不detach，线程结束后资源不会被自动回收。
- 把线程标记为detached后，线程结束时资源由系统自动回收，之后不能再对它调用`pthread_join`。
- 主线程不会因为detach而等待子线程，所以主线程先退出时整个进程退出，子线程会被强制终止。要保证回收线程就要保证主线程结束的时间比子线程慢。

### pthread_cancel

`int pthread_cancel(pthread_t thread);`

- 向目标线程发送取消请求，目标线程是否响应以及何时响应取决于它的取消状态和取消类型。
- 取消状态：`PTHREAD_CANCEL_ENABLE`（默认）或`PTHREAD_CANCEL_DISABLE`。
- 取消类型：`PTHREAD_CANCEL_ASYNCHRONOUS`（异步）或`PTHREAD_CANCEL_DEFERRED`（默认）。
- deferred模式下，取消请求会挂起，直到线程执行取消点函数（如`sleep`、`pthread_testcancel`）时才会真正取消；asynchronous模式下，线程可能在任何时候被取消，但系统不保证立即取消。
- `pthread_cancel`返回只能表示取消请求发送成功，不能判断线程是否已经取消；通过`pthread_join`返回`PTHREAD_CANCELED`才是判断取消完成的依据。

### pthread_setcancelstate 和 pthread_setcanceltype

`int pthread_setcancelstate(int state, int *oldstate);`

`int pthread_setcanceltype(int type, int *oldtype);`

- 用于设置取消状态和取消类型的函数
- `state`取`PTHREAD_CANCEL_ENABLE`或`PTHREAD_CANCEL_DISABLE`，`type`取`PTHREAD_CANCEL_DEFERRED`或`PTHREAD_CANCEL_ASYNCHRONOUS`。
- `oldstate`和`oldtype`用于返回原来的状态，不需要时可以传`NULL`。
- 禁用取消状态后，即使设置异步取消，线程也不会被取消。
