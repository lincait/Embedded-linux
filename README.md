# 嵌入式Linux学习笔记

## 关于本仓库
本仓库记录嵌入式Linux系统学习过程中的理论知识、调试经验和项目复盘。
目标是构建完整的嵌入式Linux知识体系，从C语言基础到驱动开发。

## 目录结构
- `01_C语言基础补充/` - C语言核心知识查漏补缺
- `02_数据结构/` - 嵌入式常用数据结构
- `03_Linux系统编程/` - Linux系统编程与应用开发
- `参考资料/` - 学习过程参考的文档
- `调试记录/` - 遇到的Bug与解决方案
- `工具与工具链/` - 相关工具链简单用法
